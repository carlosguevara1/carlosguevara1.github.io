# Research Software

<h2><a href="https://github.com/d2cml-ai/csdid" target="_blank">csdid: Difference-in-Differences with Multiple Time Periods</a></h2>

[![PyPI version](https://img.shields.io/pypi/v/csdid.svg?color=blue)](https://pypi.org/project/csdid/)
[![Downloads](https://static.pepy.tech/personalized-badge/csdid?period=total&units=international_system&left_color=blue&right_color=grey&left_text=Downloads)](https://pepy.tech/project/csdid)
[![Last commit](https://img.shields.io/github/last-commit/d2cml-ai/csdid.svg)](https://github.com/d2cml-ai/csdid/commits/main)
[![GitHub stars](https://img.shields.io/github/stars/d2cml-ai/csdid.svg?style=social)](https://github.com/d2cml-ai/csdid/stargazers)
[![GitHub issues](https://img.shields.io/github/issues/d2cml-ai/csdid.svg)](https://github.com/d2cml-ai/csdid/issues)
[![License](https://img.shields.io/github/license/d2cml-ai/csdid.svg)](https://github.com/d2cml-ai/csdid/blob/main/LICENSE)

<p><strong>csdid</strong> is a Python implementation of the Difference-in-Differences estimator with multiple time periods proposed by Callaway and Sant'Anna (2021). The package has surpassed <strong>400,000 downloads</strong>.</p>

<p>Developed by <a href="https://alexanderquispe.github.io/" target="_blank">Alexander Quispe</a> and <a href="https://carlosguevara1.github.io/" target="_blank">Carlos Guevara</a>, in collaboration with <a href="https://psantanna.com/" target="_blank">Pedro H. C. Sant'Anna</a> and <a href="https://bcallaway11.github.io/index.html" target="_blank">Brantly Callaway</a>.</p>

<p>My contributions include treatment-effect aggregation and visualization tools.</p>

<p>Reference: Callaway, B., & Sant'Anna, P. H. C. (2021). Difference-in-Differences with Multiple Time Periods. <em>Journal of Econometrics</em>, 225(2), 200-230. <a href="https://www.sciencedirect.com/science/article/abs/pii/S0304407620303948" target="_blank">[Paper]</a></p>
